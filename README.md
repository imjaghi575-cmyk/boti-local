# 🤖 Boti Local

دستیار محلی فارسی، امن و سبک برای اجرای مستقیم در Termux؛ بدون وابستگی اجباری به اینترنت.

## امکانات

- رابط ترمینالی سازگار با UTF-8 و حالت بدون رنگ
- نرمال‌سازی حروف فارسی/عربی و اعداد فارسی
- حافظه محلی محدود با ذخیره‌سازی اتمیک و سطح دسترسی محدود
- حافظه نام، یادداشت، ترجیحات و زمینه کوتاه مکالمه
- دستورات فارسی و انگلیسی برای مدیریت حافظه، تکرار، زمان، تاریخ و محاسبه
- ماشین‌حساب امن مبتنی بر AST؛ بدون `eval`، shell یا اجرای کد کاربر
- محدودیت طول ورودی، تعداد آیتم‌های حافظه و پیچیدگی عبارت ریاضی
- تست خودکار در چند نسخه Python با GitHub Actions

## اجرا در Termux

```bash
pkg update -y
pkg install python git -y
git clone https://github.com/imjaghi575-cmyk/boti-local.git
cd boti-local
python main.py
```

## فرمان‌ها

- `/help` یا `/راهنما` — نمایش راهنما
- `/memory` — نمایش حافظه
- `/stats` — نمایش آمار حافظه و زمینه
- `/remember کلید=مقدار` — ذخیره یادداشت
- `/recall کلید` — بازیابی یادداشت
- `/forget کلید` — حذف یادداشت
- `/forget-name` — حذف نام ذخیره‌شده
- `/clear` — پاک‌کردن حافظه و زمینه
- `/time` و `/date` — زمان و تاریخ سیستم
- `/calc 12+8` — محاسبه امن
- `/repeat متن` — تکرار متن
- `/about` — اطلاعات ربات
- `/exit` — خروج

## نمونه گفت‌وگو

```text
اسم من علی است
یادم باشه: زبان مورد علاقه=پایتون
/recall زبان مورد علاقه
/calc 12*(3+2)
```

## حریم خصوصی و امنیت

- داده‌ها فقط در فایل محلی `data/memory.json` ذخیره می‌شوند.
- برای حذف کامل داده‌ها از `/clear` یا `/forget` استفاده کنید.
- فایل حافظه را به اشتراک نگذارید؛ ممکن است متن گفتگو و یادداشت‌های شخصی داشته باشد.
- ربات به‌صورت پیش‌فرض آفلاین است و به سرویس بیرونی نیاز ندارد.
- نمایش راست‌به‌چپ به فونت و موتور ترمینال وابسته است.

## رفع مشکل فارسی

از نسخه به‌روز Termux و فونت دارای پشتیبانی فارسی استفاده کنید. در صورت نیاز:

```bash
pkg install ncurses-utils -y
```
