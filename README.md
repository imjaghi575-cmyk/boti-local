# 🤖 Boti Local

دستیار محلی فارسی با رابط اختصاصی ترمینال، مناسب اجرای مستقیم در Termux.

## امکانات

- رابط ترمینالی سازگار با UTF-8 و حالت بدون رنگ برای خروجی‌های غیرتعاملی
- پاسخ‌های پایه فارسی و نرمال‌سازی حروف فارسی/عربی
- حافظه محلی محدود و قابل پاک‌سازی
- ذخیره‌سازی اتمیک برای کاهش احتمال خراب‌شدن فایل حافظه
- بدون کتابخانه خارجی و بدون اجرای shell، `eval` یا کد دریافتی از کاربر
- محدودیت طول پیام برای مصرف کنترل‌شده منابع

## اجرا در Termux

```bash
pkg update -y
pkg install python git -y
git clone https://github.com/imjaghi575-cmyk/boti-local.git
cd boti-local
python main.py
```

## فرمان‌ها

- `/help` نمایش راهنما
- `/memory` نمایش ۱۰ مورد آخر حافظه
- `/forget` حذف کامل حافظه محلی
- `/clear` پاک‌کردن صفحه
- `/about` اطلاعات ربات
- `/exit` خروج

## حریم خصوصی و امنیت

- داده‌ها فقط در فایل محلی `data/memory.json` ذخیره می‌شوند.
- برای حذف داده‌های ذخیره‌شده از `/forget` استفاده کنید.
- فایل حافظه را با دیگران به اشتراک نگذارید؛ ممکن است شامل متن گفتگو باشد.
- ربات آفلاین است و هیچ تضمینی درباره شکل‌دهی کامل راست‌به‌چپ در همه ترمینال‌ها وجود ندارد.

## رفع مشکل فارسی

از نسخه به‌روز Termux و فونت دارای پشتیبانی فارسی استفاده کنید. در صورت نیاز:

```bash
pkg install ncurses-utils -y
```

نمایش راست‌به‌چپ به فونت و موتور ترمینال وابسته است.
